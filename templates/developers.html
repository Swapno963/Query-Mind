3. Profile (optional)

curl -X PUT {{ api_origin }}/api/v1/profile/ \
  --header "x-api-key: $QUERYMIND_API_KEY" \
  --header "content-type: application/json" \
  --data '{"industry":"Retail / e-commerce","business":"We sell online.","keeps":["orders"]}'

4. Discover tables and columns

Get the SQL, run it on your Postgres, then post the rows. QueryMind saves the catalog on your API workspace only.

curl {{ api_origin }}/api/v1/discover/instructions/ \
  --header "x-api-key: $QUERYMIND_API_KEY"

curl -X POST {{ api_origin }}/api/v1/discover/ \
  --header "x-api-key: $QUERYMIND_API_KEY" \
  --header "content-type: application/json" \
  --data '{"rows":[{"table_name":"orders","column_name":"id"},{"table_name":"orders","column_name":"status"}]}'

5. Allow-list

Invented names are ignored. Each allowed table needs at least one discovered column.

curl -X PUT {{ api_origin }}/api/v1/access/ \
  --header "x-api-key: $QUERYMIND_API_KEY" \
  --header "content-type: application/json" \
  --data '{"allowed_tables":["orders"],"allowed_columns":{"orders":["id","status"]}}'

6. Messages

Ask a question. QueryMind returns SQL. You execute it. Then post rows for a natural-language answer.

curl -X POST {{ api_origin }}/api/v1/messages/ \
  --header "x-api-key: $QUERYMIND_API_KEY" \
  --header "content-type: application/json" \
  --data '{"content":"How many unpaid orders?"}'

curl -X POST {{ api_origin }}/api/v1/messages/results/ \
  --header "x-api-key: $QUERYMIND_API_KEY" \
  --header "content-type: application/json" \
  --data '{"user_message_id":12,"rows":[{"n":12}]}'
